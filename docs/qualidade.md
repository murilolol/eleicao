# Qualidade e confiabilidade

A plataforma valida a consulta em camadas: fonte, importação, agregação, API e interface.

- Arquivos oficiais conservam referência, checksum e schema observado.
- Códigos territoriais são validados antes das junções.
- Ausências, cobertura incompleta e falhas de fonte permanecem explícitas.
- Valores e referências não são substituídos silenciosamente entre eleições.
- Dados individuais desnecessários não são publicados.
- Testes automatizados verificam contratos de privacidade, somas, cache, proveniência, filtros e resultados.
- Desktop e celular têm conferência visual com capturas reais.

A atualização do explorador passou em **136 testes**, lint de UI e build. Isso descreve a verificação realizada, sem constituir garantia de ausência universal de falhas.

A [metodologia](metodologia.md) e a [cobertura](cobertura.md) permitem avaliar os limites das informações. A [galeria](galeria.md) identifica as telas e o instante das capturas.
